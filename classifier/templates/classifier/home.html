The approach

We trained a convolutional network on MNIST using a validation split rather than cross-validation, since retraining a CNN repeatedly for cross-validation is slow. Several architectures were tried — varying the number and size of convolutional filters, the number of pooling layers, and the use of dropout — before settling on the configuration described below.
